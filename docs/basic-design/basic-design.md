# 基本設計

## 1. システム概要

残業時間を記録し、月間残業時間およびHPを可視化する
Spring Boot製Webアプリケーション。

---

## 2. システム構成

### 使用技術

| 分類 | 技術 |
|---|---|
| 言語 | Java 21 |
| フレームワーク | Spring Boot |
| テンプレートエンジン | Thymeleaf |
| ビルドツール | Maven |
| データベース | 未定 |
| バージョン管理 | Git / GitHub |

### アプリケーション構成

以下の構成を基本とする。

- Controller
- Service
- Repository
- Entity
- View（Thymeleaf）

---

## 3. 画面一覧

| 画面ID | 画面名 | 概要 |
|---|---|---|
| SCR-001 | ホーム画面 | 現在HP、月間残業時間、状態を表示する |

## 6. データ設計概要

### 残業記録

| 項目 | 概要 |
|---|---|
| ID | 残業記録を識別するID |
| 日付 | 残業した日 |
| 残業時間 | 当日の残業時間 |
| 登録日時 | データを登録した日時 |
| 更新日時 | データを更新した日時 |

※ データ型や桁数などの詳細は詳細設計で定義する。

---

## 7. HP機能概要

- HPの最大値は100とする
- 当月の残業時間をもとにHPを算出する
- HPは0未満にならない
- HPに応じて状態を表示する
- HPの具体的な計算式は詳細設計で定義する

---

## 8. 入力チェック概要

残業登録時に以下をチェックする。

- 日付が入力されていること
- 残業時間が入力されていること
- 不正な残業時間が入力されていないこと

具体的なチェック条件・エラーメッセージは詳細設計で定義する。

---

## 9. エラー処理概要

- 入力エラーの場合は画面上にメッセージを表示する
- システムエラー発生時はエラー画面を表示する
