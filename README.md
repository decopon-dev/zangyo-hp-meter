# 残業HPメーター

残業時間をHP（体力）として可視化するWebアプリケーションです。

## 概要

残業時間が増えるほどHPが減っていきます。

「今月どれくらい働きすぎているのか」を、
ゲーム感覚で分かりやすく確認できるアプリを目指しています。

## 主な機能

- 残業時間の記録
- 残業時間に応じたHPの減少
- 月間残業時間の表示

※ 現在開発中です。

## 使用技術

- Java 21
- Spring Boot
- Thymeleaf
- Maven

## 開発方針

AIを活用しながら開発しています。

ただし、GitHubにpushするコードは、
自分で内容を説明できるコードだけにします。
